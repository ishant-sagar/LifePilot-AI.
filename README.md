# LifePilot AI

### A Personalized Daily Life and Study Planner

LifePilot AI is a student-focused planning prototype designed to help students balance academics, personal habits, sports, family time, and career development.

## Problem Statement
Students often struggle to manage study schedules alongside daily responsibilities, healthy habits, and career preparation. They need a simple way to organize their time and track their progress.

## Current Features
- Daily task and routine planning
- Study and activity tracking
- Task completion and progress monitoring
- Daily reflection journal
- Rule-based study and career suggestions
- Browser-based local data storage

## Target Users
- AI/ML and Computer Science students
- JEE and NEET aspirants
- Students preparing for internships and competitive examinations

## Technology Stack
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Download `LifePilot_AI_MVP.html`.
2. Open the file in Google Chrome or another modern browser.
3. Add tasks and explore the planner.

## Future Improvements
- AI-powered personalized planning
- Smarter recommendations based on available time
- Study reminders and target tracking
- Career preparation and internship planning

## Current Status
This is an early-stage prototype. AI model integration is not yet implemented.
